# SEO — Ascenda Logistics

## Implementado
- títulos e descrições únicos
- canonical
- `lang=pt-BR`
- sitemap e robots
- llms.txt
- Organization, WebSite e Service JSON-LD
- arquitetura de URLs semânticas
- cluster inicial: captação de embarcadores, marketing para transportadoras, perfil logístico
- links internos crawlable
- headings semânticos
- alt/labels de acessibilidade
- OG image e Twitter Card
- performance e sem dependência de JS para conteúdo principal

## Depois do deploy
1. Validar domínio no Google Search Console.
2. Enviar `/sitemap.xml`.
3. Inspecionar Home e páginas estratégicas.
4. Configurar Google Business Profile com o domínio novo.
5. Criar páginas/cases com conteúdo original e dados autorizados.
6. Publicar conteúdo recorrente para termos de cauda longa.
7. Conquistar links editoriais/parcerias do setor logístico.
8. Monitorar consultas, CTR e páginas em crescimento.
9. Atualizar titles/copys com base em dados, não por achismo.
10. Evitar conteúdo gerado em massa sem valor.

## Core Web Vitals
Metas: LCP <= 2,5s, INP < 200ms, CLS baixo. Testar em dados de campo após produção.
