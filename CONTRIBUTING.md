# Contribuindo
Leia primeiro `AGENTS.md` e `PROJECT.md`.

## Fluxo
Issue → branch → implementação → lint/testes → PR mencionando Issue → revisão → deploy.

## Branches
- `fix/<issue>-descricao`
- `feat/<issue>-descricao`
- `improve/<issue>-descricao`
- `seo/<issue>-descricao`

## Commits
Conventional Commits: `feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`.
